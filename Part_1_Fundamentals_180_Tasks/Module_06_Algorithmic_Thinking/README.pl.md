# Moduł 6: Myślenie Programistyczne (Wzorzec IPO)

[🇬🇧 English](README.md) | [🇵🇱 Polski](README.pl.md)

---

## 🎯 O tym module
Strukturyzacja programów w oparciu o przewidywalny wzorzec Wejście -> Przetwarzanie -> Wyjście.

- **Limit wizualny:** Maksymalnie 88 znaków w wierszu (standard PEP 8 / Black).
- **Format:** 15 praktycznych zadań krok po kroku z gotowymi rozwiązaniami w języku angielskim.

---

## 📝 15 Praktycznych Zadań

### Zadanie 01: IPO Pattern: Rectangle Area
- **Treść:** Napisz program obliczający pole prostokąta. Podziel kod na trzy sekcje: wejście, przetwarzanie, wyjście.
- **EN:** Calculate rectangle area dividing code explicitly into: Input, Process, Output.
- **Rozwiązanie:** [`solutions/task_01.py`](solutions/task_01.py)
### Zadanie 02: IPO Pattern: User Profile Bio
- **Treść:** Napisz program, który pobiera imię, wiek i miasto, a następnie wyświetla zdanie z tymi danymi.
- **EN:** Prompt for name, age, city, process into bio record, and display.
- **Rozwiązanie:** [`solutions/task_02.py`](solutions/task_02.py)
### Zadanie 03: IPO Pattern: BMI Calculator
- **Treść:** Napisz program obliczający BMI (waga w kg, wzrost w m) – wzór: `waga / wzrost²`.
- **EN:** Calculate Body Mass Index (weight in kg, height in m) using formula: weight / height^2.
- **Rozwiązanie:** [`solutions/task_03.py`](solutions/task_03.py)
### Zadanie 04: IPO Pattern: Distance Unit Converter
- **Treść:** Napisz program przeliczający kilometry na mile (1 mila = 1.609344 km).
- **EN:** Convert kilometers to miles (1 mile = 1.609344 km).
- **Rozwiązanie:** [`solutions/task_04.py`](solutions/task_04.py)
### Zadanie 05: IPO Pattern: Academic Grade Average
- **Treść:** Napisz program, który pobiera trzy oceny (1–6) i oblicza średnią arytmetyczną.
- **EN:** Prompt for three grades (1 to 6) and compute arithmetic average.
- **Rozwiązanie:** [`solutions/task_05.py`](solutions/task_05.py)
### Zadanie 06: IPO Pattern: Time Conversion
- **Treść:** Napisz program zamieniający podaną liczbę godzin na minuty i sekundy.
- **EN:** Convert hours into minutes and seconds.
- **Rozwiązanie:** [`solutions/task_06.py`](solutions/task_06.py)
### Zadanie 07: IPO Pattern: Year to Day Counter
- **Treść:** Napisz program obliczający liczbę dni w podanej liczbie lat (bez lat przestępnych).
- **EN:** Calculate number of days in a given number of non-leap years (365 days/year).
- **Rozwiązanie:** [`solutions/task_07.py`](solutions/task_07.py)
### Zadanie 08: IPO Pattern: Currency Converter
- **Treść:** Napisz program przeliczający kwotę w PLN na EUR (kurs: 1 EUR = 4.30 PLN).
- **EN:** Convert amount from PLN to EUR using exchange rate 1 EUR = 4.30 PLN.
- **Rozwiązanie:** [`solutions/task_08.py`](solutions/task_08.py)
### Zadanie 09: IPO Pattern: Trapezoid Area
- **Treść:** Napisz program obliczający pole trapezu według wzoru: `P = ((a + b) * h) / 2`.
- **EN:** Calculate trapezoid area with formula: area = ((a + b) * h) / 2.
- **Rozwiązanie:** [`solutions/task_09.py`](solutions/task_09.py)
### Zadanie 10: IPO Pattern: Speed and Distance
- **Treść:** Napisz program, który pobiera prędkość (km/h) i czas (h), a następnie oblicza dystans.
- **EN:** Prompt for speed (km/h) and time (h), then compute travelled distance.
- **Rozwiązanie:** [`solutions/task_10.py`](solutions/task_10.py)
### Zadanie 11: IPO Pattern: Discount Calculator
- **Treść:** Napisz program obliczający cenę po rabacie 20% od podanej ceny.
- **EN:** Calculate final price after applying a 20% discount to an initial price.
- **Rozwiązanie:** [`solutions/task_11.py`](solutions/task_11.py)
### Zadanie 12: IPO Pattern: Reverse Three Numbers
- **Treść:** Napisz program, który pobiera trzy liczby i wyświetla je w odwrotnej kolejności.
- **EN:** Prompt for three numbers and display them in reverse order.
- **Rozwiązanie:** [`solutions/task_12.py`](solutions/task_12.py)
### Zadanie 13: IPO Pattern: Text Multiplier
- **Treść:** Napisz program, który pobiera tekst i liczbę `n`, a następnie wyświetla tekst `n` razy.
- **EN:** Prompt for text and integer n, then repeat the text n times.
- **Rozwiązanie:** [`solutions/task_13.py`](solutions/task_13.py)
### Zadanie 14: IPO Pattern: CLI Calculator
- **Treść:** Napisz prosty kalkulator – pobiera dwie liczby i znak działania (+, -, *, /), wyświetla wynik.
- **EN:** Prompt for two numbers and operator (+, -, *, /), then evaluate.
- **Rozwiązanie:** [`solutions/task_14.py`](solutions/task_14.py)
### Zadanie 15: IPO Pattern: Triangle Area
- **Treść:** Napisz program obliczający pole trójkąta ((podstawa * wysokość) / 2).
- **EN:** Calculate triangle area using formula: (base * height) / 2.
- **Rozwiązanie:** [`solutions/task_15.py`](solutions/task_15.py)
