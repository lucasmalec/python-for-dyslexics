# Module 6: Algorithmic Thinking (IPO Pattern)

[🇬🇧 English](README.md) | [🇵🇱 Polski](README.pl.md)

---

## 🎯 About This Module
Structure scripts using the predictable Input -> Process -> Output architectural paradigm.

- **Visual Limit:** Max 88 characters per line (PEP 8 / Black standard).
- **Format:** 15 hands-on progressive tasks with full English solutions.

---

## 📝 15 Hands-on Tasks

### Task 01: IPO Pattern: Rectangle Area
- **Requirement:** Calculate rectangle area dividing code explicitly into: Input, Process, Output.
- **PL:** Napisz program obliczający pole prostokąta. Podziel kod na trzy sekcje: wejście, przetwarzanie, wyjście.
- **Solution:** [`solutions/task_01.py`](solutions/task_01.py)
### Task 02: IPO Pattern: User Profile Bio
- **Requirement:** Prompt for name, age, city, process into bio record, and display.
- **PL:** Napisz program, który pobiera imię, wiek i miasto, a następnie wyświetla zdanie z tymi danymi.
- **Solution:** [`solutions/task_02.py`](solutions/task_02.py)
### Task 03: IPO Pattern: BMI Calculator
- **Requirement:** Calculate Body Mass Index (weight in kg, height in m) using formula: weight / height^2.
- **PL:** Napisz program obliczający BMI (waga w kg, wzrost w m) – wzór: `waga / wzrost²`.
- **Solution:** [`solutions/task_03.py`](solutions/task_03.py)
### Task 04: IPO Pattern: Distance Unit Converter
- **Requirement:** Convert kilometers to miles (1 mile = 1.609344 km).
- **PL:** Napisz program przeliczający kilometry na mile (1 mila = 1.609344 km).
- **Solution:** [`solutions/task_04.py`](solutions/task_04.py)
### Task 05: IPO Pattern: Academic Grade Average
- **Requirement:** Prompt for three grades (1 to 6) and compute arithmetic average.
- **PL:** Napisz program, który pobiera trzy oceny (1–6) i oblicza średnią arytmetyczną.
- **Solution:** [`solutions/task_05.py`](solutions/task_05.py)
### Task 06: IPO Pattern: Time Conversion
- **Requirement:** Convert hours into minutes and seconds.
- **PL:** Napisz program zamieniający podaną liczbę godzin na minuty i sekundy.
- **Solution:** [`solutions/task_06.py`](solutions/task_06.py)
### Task 07: IPO Pattern: Year to Day Counter
- **Requirement:** Calculate number of days in a given number of non-leap years (365 days/year).
- **PL:** Napisz program obliczający liczbę dni w podanej liczbie lat (bez lat przestępnych).
- **Solution:** [`solutions/task_07.py`](solutions/task_07.py)
### Task 08: IPO Pattern: Currency Converter
- **Requirement:** Convert amount from PLN to EUR using exchange rate 1 EUR = 4.30 PLN.
- **PL:** Napisz program przeliczający kwotę w PLN na EUR (kurs: 1 EUR = 4.30 PLN).
- **Solution:** [`solutions/task_08.py`](solutions/task_08.py)
### Task 09: IPO Pattern: Trapezoid Area
- **Requirement:** Calculate trapezoid area with formula: area = ((a + b) * h) / 2.
- **PL:** Napisz program obliczający pole trapezu według wzoru: `P = ((a + b) * h) / 2`.
- **Solution:** [`solutions/task_09.py`](solutions/task_09.py)
### Task 10: IPO Pattern: Speed and Distance
- **Requirement:** Prompt for speed (km/h) and time (h), then compute travelled distance.
- **PL:** Napisz program, który pobiera prędkość (km/h) i czas (h), a następnie oblicza dystans.
- **Solution:** [`solutions/task_10.py`](solutions/task_10.py)
### Task 11: IPO Pattern: Discount Calculator
- **Requirement:** Calculate final price after applying a 20% discount to an initial price.
- **PL:** Napisz program obliczający cenę po rabacie 20% od podanej ceny.
- **Solution:** [`solutions/task_11.py`](solutions/task_11.py)
### Task 12: IPO Pattern: Reverse Three Numbers
- **Requirement:** Prompt for three numbers and display them in reverse order.
- **PL:** Napisz program, który pobiera trzy liczby i wyświetla je w odwrotnej kolejności.
- **Solution:** [`solutions/task_12.py`](solutions/task_12.py)
### Task 13: IPO Pattern: Text Multiplier
- **Requirement:** Prompt for text and integer n, then repeat the text n times.
- **PL:** Napisz program, który pobiera tekst i liczbę `n`, a następnie wyświetla tekst `n` razy.
- **Solution:** [`solutions/task_13.py`](solutions/task_13.py)
### Task 14: IPO Pattern: CLI Calculator
- **Requirement:** Prompt for two numbers and operator (+, -, *, /), then evaluate.
- **PL:** Napisz prosty kalkulator – pobiera dwie liczby i znak działania (+, -, *, /), wyświetla wynik.
- **Solution:** [`solutions/task_14.py`](solutions/task_14.py)
### Task 15: IPO Pattern: Triangle Area
- **Requirement:** Calculate triangle area using formula: (base * height) / 2.
- **PL:** Napisz program obliczający pole trójkąta ((podstawa * wysokość) / 2).
- **Solution:** [`solutions/task_15.py`](solutions/task_15.py)
