# Moduł 1: Zmienne i Przypisywanie Wartości

[🇬🇧 English](README.md) | [🇵🇱 Polski](README.pl.md)

---

## 🎯 O tym module
Nauka deklaracji zmiennych, nadpisywania wartości, dynamicznego typowania oraz konwencji nazewnictwa w Pythonie.

- **Limit wizualny:** Maksymalnie 88 znaków w wierszu (standard PEP 8 / Black).
- **Format:** 15 praktycznych zadań krok po kroku z gotowymi rozwiązaniami w języku angielskim.

---

## 📝 15 Praktycznych Zadań

### Zadanie 01: Variable Assignment
- **Treść:** Stwórz zmienną `imie` i przypisz do niej swoje imię. Wyświetl ją.
- **EN:** Create a variable `user_name` and assign your name to it. Print it.
- **Rozwiązanie:** [`solutions/task_01.py`](solutions/task_01.py)
### Zadanie 02: Variable Reassignment
- **Treść:** Stwórz zmienną `wiek` z wartością 25, a następnie zmień jej wartość na 26. Wyświetl obie wartości.
- **EN:** Create a variable `age` with value 25, then update it to 26. Print both.
- **Rozwiązanie:** [`solutions/task_02.py`](solutions/task_02.py)
### Zadanie 03: Arithmetic Sum
- **Treść:** Utwórz zmienne `a = 7` i `b = 3`. Oblicz ich sumę i zapisz w zmiennej `suma`. Wyświetl `suma`.
- **EN:** Create variables `a = 7` and `b = 3`. Calculate their sum in `total_sum` and print.
- **Rozwiązanie:** [`solutions/task_03.py`](solutions/task_03.py)
### Zadanie 04: Overwriting Variables
- **Treść:** Nadpisz zmienną `suma` wynikiem mnożenia `a` i `b`. Wyświetl nową wartość.
- **EN:** Overwrite variable `total_sum` with the product of `a` and `b`. Print the new value.
- **Rozwiązanie:** [`solutions/task_04.py`](solutions/task_04.py)
### Zadanie 05: Rectangle Area
- **Treść:** Utwórz zmienne `szerokosc = 5` i `wysokosc = 10`. Oblicz pole prostokąta i zapisz w zmiennej `pole`.
- **EN:** Create variables `width = 5` and `height = 10`. Calculate rectangle area into `area`.
- **Rozwiązanie:** [`solutions/task_05.py`](solutions/task_05.py)
### Zadanie 06: Gross Price and VAT Calculation
- **Treść:** Utwórz zmienną `cena_netto = 100` i `vat = 0.23`. Oblicz `cena_brutto` i wyświetl. Zawiera interaktywność i ochronę przed ujemnym VAT.
- **EN:** Create variables `net_price = 100` and `vat_rate = 0.23`. Calculate `gross_price` and display. Includes defensive negative VAT check.
- **Rozwiązanie:** [`solutions/task_06.py`](solutions/task_06.py)
### Zadanie 07: Renaming Variables
- **Treść:** Zmień nazwę zmiennej `stara` na `nowa` (przypisz wartość z `stara` do `nowa`, a `stara` usuń).
- **EN:** Rename variable `old_var` to `new_var` (assign `old_var` to `new_var`, then delete `old_var`).
- **Rozwiązanie:** [`solutions/task_07.py`](solutions/task_07.py)
### Zadanie 08: Dynamic Typing
- **Treść:** Utwórz zmienną `liczba = 42`, a następnie przypisz do niej napis 'czterdzieści dwa'. Wyświetl zmienną.
- **EN:** Create variable `number = 42`, then reassign it to string 'forty-two'. Print value and type.
- **Rozwiązanie:** [`solutions/task_08.py`](solutions/task_08.py)
### Zadanie 09: Multiple Assignment
- **Treść:** W jednej linii utwórz zmienne `x`, `y`, `z` i przypisz im wartości 1, 2, 3.
- **EN:** In a single line, assign values 1, 2, 3 to variables `x`, `y`, `z`.
- **Rozwiązanie:** [`solutions/task_09.py`](solutions/task_09.py)
### Zadanie 10: Internal Variable Naming
- **Treść:** Utwórz zmienną `_prywatna` z wartością 'tajne' i wyświetl ją.
- **EN:** Create an internal variable `_secret_key = 'secret'` and print it.
- **Rozwiązanie:** [`solutions/task_10.py`](solutions/task_10.py)
### Zadanie 11: Long String Variable
- **Treść:** Utwórz zmienną `dlugi_opis` zawierającą tekst: 'Python to język programowania wysokiego poziomu.'
- **EN:** Create variable `long_description` with text: 'Python is a high-level programming language.'
- **Rozwiązanie:** [`solutions/task_11.py`](solutions/task_11.py)
### Zadanie 12: Case Sensitivity
- **Treść:** Utwórz zmienne `wiekOsoby` i `wiek_osoby` z różnymi wartościami. Sprawdź, czy Python traktuje je jako różne.
- **EN:** Create variables `personAge` and `person_age` with different values. Check if Python treats them as distinct.
- **Rozwiązanie:** [`solutions/task_12.py`](solutions/task_12.py)
### Zadanie 13: Self-referential Arithmetic
- **Treść:** Utwórz zmienną `temp = 15`, a następnie nadpisz ją wynikiem działania `temp * 2 + 5`.
- **EN:** Create variable `temp = 15`, then overwrite it with `temp * 2 + 5`.
- **Rozwiązanie:** [`solutions/task_13.py`](solutions/task_13.py)
### Zadanie 14: Floating-Point Division
- **Treść:** Utwórz zmienną `wynik_dzielenia = 15 / 4` i wyświetl jej wartość.
- **EN:** Create variable `division_result = 15 / 4` and display its value and type.
- **Rozwiązanie:** [`solutions/task_14.py`](solutions/task_14.py)
### Zadanie 15: NoneType Evaluation
- **Treść:** Utwórz zmienną `pusty` z wartością `None`, a następnie sprawdź jej typ za pomocą `type()`.
- **EN:** Create variable `empty_val = None`, then inspect its type with `type()`.
- **Rozwiązanie:** [`solutions/task_15.py`](solutions/task_15.py)
