# Module 1: Variables & Assignment

[🇬🇧 English](README.md) | [🇵🇱 Polski](README.pl.md)

---

## 🎯 About This Module
Master variable declaration, reassignment, dynamic typing, naming conventions, and fundamental memory references.

- **Visual Limit:** Max 88 characters per line (PEP 8 / Black standard).
- **Format:** 15 hands-on progressive tasks with full English solutions.

---

## 📝 15 Hands-on Tasks

### Task 01: Variable Assignment
- **Requirement:** Create a variable `user_name` and assign your name to it. Print it.
- **PL:** Stwórz zmienną `imie` i przypisz do niej swoje imię. Wyświetl ją.
- **Solution:** [`solutions/task_01.py`](solutions/task_01.py)
### Task 02: Variable Reassignment
- **Requirement:** Create a variable `age` with value 25, then update it to 26. Print both.
- **PL:** Stwórz zmienną `wiek` z wartością 25, a następnie zmień jej wartość na 26. Wyświetl obie wartości.
- **Solution:** [`solutions/task_02.py`](solutions/task_02.py)
### Task 03: Arithmetic Sum
- **Requirement:** Create variables `a = 7` and `b = 3`. Calculate their sum in `total_sum` and print.
- **PL:** Utwórz zmienne `a = 7` i `b = 3`. Oblicz ich sumę i zapisz w zmiennej `suma`. Wyświetl `suma`.
- **Solution:** [`solutions/task_03.py`](solutions/task_03.py)
### Task 04: Overwriting Variables
- **Requirement:** Overwrite variable `total_sum` with the product of `a` and `b`. Print the new value.
- **PL:** Nadpisz zmienną `suma` wynikiem mnożenia `a` i `b`. Wyświetl nową wartość.
- **Solution:** [`solutions/task_04.py`](solutions/task_04.py)
### Task 05: Rectangle Area
- **Requirement:** Create variables `width = 5` and `height = 10`. Calculate rectangle area into `area`.
- **PL:** Utwórz zmienne `szerokosc = 5` i `wysokosc = 10`. Oblicz pole prostokąta i zapisz w zmiennej `pole`.
- **Solution:** [`solutions/task_05.py`](solutions/task_05.py)
### Task 06: Gross Price and VAT Calculation
- **Requirement:** Create variables `net_price = 100` and `vat_rate = 0.23`. Calculate `gross_price` and display. Includes defensive negative VAT check.
- **PL:** Utwórz zmienną `cena_netto = 100` i `vat = 0.23`. Oblicz `cena_brutto` i wyświetl. Zawiera interaktywność i ochronę przed ujemnym VAT.
- **Solution:** [`solutions/task_06.py`](solutions/task_06.py)
### Task 07: Renaming Variables
- **Requirement:** Rename variable `old_var` to `new_var` (assign `old_var` to `new_var`, then delete `old_var`).
- **PL:** Zmień nazwę zmiennej `stara` na `nowa` (przypisz wartość z `stara` do `nowa`, a `stara` usuń).
- **Solution:** [`solutions/task_07.py`](solutions/task_07.py)
### Task 08: Dynamic Typing
- **Requirement:** Create variable `number = 42`, then reassign it to string 'forty-two'. Print value and type.
- **PL:** Utwórz zmienną `liczba = 42`, a następnie przypisz do niej napis 'czterdzieści dwa'. Wyświetl zmienną.
- **Solution:** [`solutions/task_08.py`](solutions/task_08.py)
### Task 09: Multiple Assignment
- **Requirement:** In a single line, assign values 1, 2, 3 to variables `x`, `y`, `z`.
- **PL:** W jednej linii utwórz zmienne `x`, `y`, `z` i przypisz im wartości 1, 2, 3.
- **Solution:** [`solutions/task_09.py`](solutions/task_09.py)
### Task 10: Internal Variable Naming
- **Requirement:** Create an internal variable `_secret_key = 'secret'` and print it.
- **PL:** Utwórz zmienną `_prywatna` z wartością 'tajne' i wyświetl ją.
- **Solution:** [`solutions/task_10.py`](solutions/task_10.py)
### Task 11: Long String Variable
- **Requirement:** Create variable `long_description` with text: 'Python is a high-level programming language.'
- **PL:** Utwórz zmienną `dlugi_opis` zawierającą tekst: 'Python to język programowania wysokiego poziomu.'
- **Solution:** [`solutions/task_11.py`](solutions/task_11.py)
### Task 12: Case Sensitivity
- **Requirement:** Create variables `personAge` and `person_age` with different values. Check if Python treats them as distinct.
- **PL:** Utwórz zmienne `wiekOsoby` i `wiek_osoby` z różnymi wartościami. Sprawdź, czy Python traktuje je jako różne.
- **Solution:** [`solutions/task_12.py`](solutions/task_12.py)
### Task 13: Self-referential Arithmetic
- **Requirement:** Create variable `temp = 15`, then overwrite it with `temp * 2 + 5`.
- **PL:** Utwórz zmienną `temp = 15`, a następnie nadpisz ją wynikiem działania `temp * 2 + 5`.
- **Solution:** [`solutions/task_13.py`](solutions/task_13.py)
### Task 14: Floating-Point Division
- **Requirement:** Create variable `division_result = 15 / 4` and display its value and type.
- **PL:** Utwórz zmienną `wynik_dzielenia = 15 / 4` i wyświetl jej wartość.
- **Solution:** [`solutions/task_14.py`](solutions/task_14.py)
### Task 15: NoneType Evaluation
- **Requirement:** Create variable `empty_val = None`, then inspect its type with `type()`.
- **PL:** Utwórz zmienną `pusty` z wartością `None`, a następnie sprawdź jej typ za pomocą `type()`.
- **Solution:** [`solutions/task_15.py`](solutions/task_15.py)
