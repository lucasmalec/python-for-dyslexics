# Moduł 12: Zadania Integracyjne

[🇬🇧 English](README.md) | [🇵🇱 Polski](README.pl.md)

---

## 🎯 O tym module
Kompleksowe projekty łączące wszystkie poznane koncepty w gotowe, produkcyjne narzędzia terminalowe.

- **Limit wizualny:** Maksymalnie 88 znaków w wierszu (standard PEP 8 / Black).
- **Format:** 15 praktycznych zadań krok po kroku z gotowymi rozwiązaniami w języku angielskim.

---

## 📝 15 Praktycznych Zadań

### Zadanie 01: Four Primitive Types Showcase
- **Treść:** Napisz program, który używa wszystkich typów danych: `int`, `float`, `str`, `bool` – wyświetl je z opisem.
- **EN:** Demonstrate int, float, str, and bool with descriptions and formatted terminal output.
- **Rozwiązanie:** [`solutions/task_01.py`](solutions/task_01.py)
### Zadanie 02: Defensive CLI Calculator
- **Treść:** Stwórz kalkulator z walidacją wejścia i obsługą błędów (dzielenie przez zero, złe dane).
- **EN:** Build a CLI calculator with input validation and zero division safeguards.
- **Rozwiązanie:** [`solutions/task_02.py`](solutions/task_02.py)
### Zadanie 03: Circle Geometry Engine
- **Treść:** Napisz program obliczający pole i obwód koła. Użyj f-stringa do wyświetlenia wyniku z 2 miejscami po przecinku.
- **EN:** Calculate circle area and circumference formatted to 2 decimal places.
- **Rozwiązanie:** [`solutions/task_03.py`](solutions/task_03.py)
### Zadanie 04: User Registration System
- **Treść:** Stwórz program rejestracyjny: pobierz imię, email, wiek. Sprawdź, czy email zawiera `@`, a wiek jest liczbą.
- **EN:** Collect name, email, and age. Validate that email contains '@' and age is integer.
- **Rozwiązanie:** [`solutions/task_04.py`](solutions/task_04.py)
### Zadanie 05: Bidirectional Temperature Converter
- **Treść:** Napisz program konwertujący temperaturę: z °C na °F i z °F na °C. Użytkownik wybiera kierunek.
- **EN:** Convert temperature between Celsius and Fahrenheit based on user choice.
- **Rozwiązanie:** [`solutions/task_05.py`](solutions/task_05.py)
### Zadanie 06: Interactive 3-Question Quiz
- **Treść:** Stwórz prosty quiz: 3 pytania. Punkty po każdej odpowiedzi.
- **EN:** Build a 3-question quiz with score tracking and summary feedback.
- **Rozwiązanie:** [`solutions/task_06.py`](solutions/task_06.py)
### Zadanie 07: Number Guessing Game
- **Treść:** Napisz program, który losuje liczbę z zakresu 1–10, a użytkownik zgaduje. Podpowiedzi: za dużo/za mało.
- **EN:** Secret number guessing game with higher/lower hints.
- **Rozwiązanie:** [`solutions/task_07.py`](solutions/task_07.py)
### Zadanie 08: Log Export Payload Simulator
- **Treść:** Stwórz program, który zapisuje wprowadzone dane do pliku (symulacja – wyświetl, co by zapisał).
- **EN:** Simulate exporting user session data into formatted log entries.
- **Rozwiązanie:** [`solutions/task_08.py`](solutions/task_08.py)
### Zadanie 09: ASCII Data Table Formatter
- **Treść:** Napisz program, który wyświetla wszystkie wprowadzone dane w formie prostej tabeli.
- **EN:** Display multiple records in an aligned ASCII terminal table.
- **Rozwiązanie:** [`solutions/task_09.py`](solutions/task_09.py)
### Zadanie 10: Interactive Multi-Menu System
- **Treść:** Stwórz program z menu: 1 – kalkulator, 2 – konwerter temperatury, 3 – wyjście. Użytkownik wybiera opcję.
- **EN:** Build a CLI menu: 1 - Calculator, 2 - Temperature Converter, 3 - Exit.
- **Rozwiązanie:** [`solutions/task_10.py`](solutions/task_10.py)
### Zadanie 11: Dictionary Profile Record
- **Treść:** Napisz program przechowujący dane w słowniku: `{'imie': '...', 'wiek': ..., 'miasto': '...'}`. Wyświetl zawartość.
- **EN:** Store user data in a dictionary: {'name': '...', 'age': ..., 'city': '...'} and display.
- **Rozwiązanie:** [`solutions/task_11.py`](solutions/task_11.py)
### Zadanie 12: Student Grade Report Generator
- **Treść:** Stwórz program generujący raport: pobierz imię, trzy oceny, oblicz średnią i wyświetl w ładnym formacie.
- **EN:** Prompt for student name and 3 grades, calculate average, and print report card.
- **Rozwiązanie:** [`solutions/task_12.py`](solutions/task_12.py)
### Zadanie 13: Continuous Loop Until Exit
- **Treść:** Napisz program, który działa w pętli aż użytkownik wpisze 'exit'. W każdej iteracji pyta o liczbę i wyświetla jej kwadrat.
- **EN:** Loop continuously requesting integers and printing their squares until user types 'exit'.
- **Rozwiązanie:** [`solutions/task_13.py`](solutions/task_13.py)
### Zadanie 14: Structured Three-Function Architecture
- **Treść:** Stwórz program podzielony na funkcje: `pobierz_dane()`, `przetworz_dane()`, `wyswietl_wynik()`.
- **EN:** Divide program into modular functions: `fetch_data()`, `process_data()`, and `display_result()`.
- **Rozwiązanie:** [`solutions/task_14.py`](solutions/task_14.py)
### Zadanie 15: Production Grade Student Assessment Engine
- **Treść:** Napisz kompletny program zgodny z PEP 8, z f-stringami, walidacją, obsługą błędów i komentarzami – np. system ocen ucznia.
- **EN:** Complete production-style application combining PEP 8, validation, f-strings, and clean architecture.
- **Rozwiązanie:** [`solutions/task_15.py`](solutions/task_15.py)
