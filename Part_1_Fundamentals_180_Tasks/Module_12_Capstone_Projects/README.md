## 🎯 About This Module
End-to-end applications synthesizing all 12 modules into robust, production-grade CLI tools.

- **Visual Limit:** Max 88 characters per line (PEP 8 / Black standard).
- **Format:** 15 hands-on progressive tasks with full English solutions.

---

## 📝 15 Hands-on Tasks

### Task 01: Four Primitive Types Showcase
- **Requirement:** Demonstrate int, float, str, and bool with descriptions and formatted terminal output.
- **PL:** Napisz program, który używa wszystkich typów danych: `int`, `float`, `str`, `bool` – wyświetl je z opisem.
- **Solution:** [`solutions/task_01.py`](solutions/task_01.py)
### Task 02: Defensive CLI Calculator
- **Requirement:** Build a CLI calculator with input validation and zero division safeguards.
- **PL:** Stwórz kalkulator z walidacją wejścia i obsługą błędów (dzielenie przez zero, złe dane).
- **Solution:** [`solutions/task_02.py`](solutions/task_02.py)
### Task 03: Circle Geometry Engine
- **Requirement:** Calculate circle area and circumference formatted to 2 decimal places.
- **PL:** Napisz program obliczający pole i obwód koła. Użyj f-stringa do wyświetlenia wyniku z 2 miejscami po przecinku.
- **Solution:** [`solutions/task_03.py`](solutions/task_03.py)
### Task 04: User Registration System
- **Requirement:** Collect name, email, and age. Validate that email contains '@' and age is integer.
- **PL:** Stwórz program rejestracyjny: pobierz imię, email, wiek. Sprawdź, czy email zawiera `@`, a wiek jest liczbą.
- **Solution:** [`solutions/task_04.py`](solutions/task_04.py)
### Task 05: Bidirectional Temperature Converter
- **Requirement:** Convert temperature between Celsius and Fahrenheit based on user choice.
- **PL:** Napisz program konwertujący temperaturę: z °C na °F i z °F na °C. Użytkownik wybiera kierunek.
- **Solution:** [`solutions/task_05.py`](solutions/task_05.py)
### Task 06: Interactive 3-Question Quiz
- **Requirement:** Build a 3-question quiz with score tracking and summary feedback.
- **PL:** Stwórz prosty quiz: 3 pytania. Punkty po każdej odpowiedzi.
- **Solution:** [`solutions/task_06.py`](solutions/task_06.py)
### Task 07: Number Guessing Game
- **Requirement:** Secret number guessing game with higher/lower hints.
- **PL:** Napisz program, który losuje liczbę z zakresu 1–10, a użytkownik zgaduje. Podpowiedzi: za dużo/za mało.
- **Solution:** [`solutions/task_07.py`](solutions/task_07.py)
### Task 08: Log Export Payload Simulator
- **Requirement:** Simulate exporting user session data into formatted log entries.
- **PL:** Stwórz program, który zapisuje wprowadzone dane do pliku (symulacja – wyświetl, co by zapisał).
- **Solution:** [`solutions/task_08.py`](solutions/task_08.py)
### Task 09: ASCII Data Table Formatter
- **Requirement:** Display multiple records in an aligned ASCII terminal table.
- **PL:** Napisz program, który wyświetla wszystkie wprowadzone dane w formie prostej tabeli.
- **Solution:** [`solutions/task_09.py`](solutions/task_09.py)
### Task 10: Interactive Multi-Menu System
- **Requirement:** Build a CLI menu: 1 - Calculator, 2 - Temperature Converter, 3 - Exit.
- **PL:** Stwórz program z menu: 1 – kalkulator, 2 – konwerter temperatury, 3 – wyjście. Użytkownik wybiera opcję.
- **Solution:** [`solutions/task_10.py`](solutions/task_10.py)
### Task 11: Dictionary Profile Record
- **Requirement:** Store user data in a dictionary: {'name': '...', 'age': ..., 'city': '...'} and display.
- **PL:** Napisz program przechowujący dane w słowniku: `{'imie': '...', 'wiek': ..., 'miasto': '...'}`. Wyświetl zawartość.
- **Solution:** [`solutions/task_11.py`](solutions/task_11.py)
### Task 12: Student Grade Report Generator
- **Requirement:** Prompt for student name and 3 grades, calculate average, and print report card.
- **PL:** Stwórz program generujący raport: pobierz imię, trzy oceny, oblicz średnią i wyświetl w ładnym formacie.
- **Solution:** [`solutions/task_12.py`](solutions/task_12.py)
### Task 13: Continuous Loop Until Exit
- **Requirement:** Loop continuously requesting integers and printing their squares until user types 'exit'.
- **PL:** Napisz program, który działa w pętli aż użytkownik wpisze 'exit'. W każdej iteracji pyta o liczbę i wyświetla jej kwadrat.
- **Solution:** [`solutions/task_13.py`](solutions/task_13.py)
### Task 14: Structured Three-Function Architecture
- **Requirement:** Divide program into modular functions: `fetch_data()`, `process_data()`, and `display_result()`.
- **PL:** Stwórz program podzielony na funkcje: `pobierz_dane()`, `przetworz_dane()`, `wyswietl_wynik()`.
- **Solution:** [`solutions/task_14.py`](solutions/task_14.py)
### Task 15: Production Grade Student Assessment Engine
- **Requirement:** Complete production-style application combining PEP 8, validation, f-strings, and clean architecture.
- **PL:** Napisz kompletny program zgodny z PEP 8, z f-stringami, walidacją, obsługą błędów i komentarzami – np. system ocen ucznia.
- **Solution:** [`solutions/task_15.py`](solutions/task_15.py)
