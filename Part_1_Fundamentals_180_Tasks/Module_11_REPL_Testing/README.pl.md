# Moduł 11: REPL i Szybkie Testowanie

[🇬🇧 English](README.md) | [🇵🇱 Polski](README.pl.md)

---

## 🎯 O tym module
Błyskawiczne prototypowanie w interaktywnej powłoce: inspekcja typów, wyrażenia i analiza błędów.

- **Limit wizualny:** Maksymalnie 88 znaków w wierszu (standard PEP 8 / Black).
- **Format:** 15 praktycznych zadań krok po kroku z gotowymi rozwiązaniami w języku angielskim.

---

## 📝 15 Praktycznych Zadań

### Zadanie 01: REPL Math Evaluation
- **Treść:** Oblicz `25 * 4 - 10`.
- **EN:** Calculate `25 * 4 - 10`.
- **Rozwiązanie:** [`solutions/task_01.py`](solutions/task_01.py)
### Zadanie 02: Type Introspection
- **Treść:** Sprawdź typ wartości 'Python' i 3.1415.
- **EN:** Inspect types of 'Python' and 3.1415 using `type()`.
- **Rozwiązanie:** [`solutions/task_02.py`](solutions/task_02.py)
### Zadanie 03: Power Calculation
- **Treść:** Utwórz zmienną `x = 6` i oblicz `x ** 3`.
- **EN:** Create `x = 6` and compute `x ** 3`.
- **Rozwiązanie:** [`solutions/task_03.py`](solutions/task_03.py)
### Zadanie 04: Lexicographical Comparison
- **Treść:** Sprawdź, czy 'banan' jest większe od 'jabłko'.
- **EN:** Check if 'banana' is greater than 'apple' in lexicographical order.
- **Rozwiązanie:** [`solutions/task_04.py`](solutions/task_04.py)
### Zadanie 05: Function Rapid Testing
- **Treść:** Zdefiniuj funkcję `kwadrat(n)` zwracającą `n * n` i przetestuj dla 7.
- **EN:** Define `square(n) -> n * n` and test it with 7.
- **Rozwiązanie:** [`solutions/task_05.py`](solutions/task_05.py)
### Zadanie 06: REPL Interactive Echo
- **Treść:** Użyj `input()` w REPL, wpisz swoje imię i wyświetl je.
- **EN:** Prompt for name in REPL style and echo it immediately.
- **Rozwiązanie:** [`solutions/task_06.py`](solutions/task_06.py)
### Zadanie 07: Padded Integer Parse
- **Treść:** Sprawdź działanie `int('   50   ')`.
- **EN:** Test how `int('   50   ')` handles leading and trailing spaces.
- **Rozwiązanie:** [`solutions/task_07.py`](solutions/task_07.py)
### Zadanie 08: Float Rounding
- **Treść:** Sprawdź, co robi `round(2.71828, 2)`.
- **EN:** Inspect behavior of `round(2.71828, 2)`.
- **Rozwiązanie:** [`solutions/task_08.py`](solutions/task_08.py)
### Zadanie 09: Truthiness of Non-Empty String
- **Treść:** Sprawdź, co zwróci `bool('False')`.
- **EN:** Inspect return value of `bool('False')`.
- **Rozwiązanie:** [`solutions/task_09.py`](solutions/task_09.py)
### Zadanie 10: Exception Inspection
- **Treść:** Spróbuj wykonać `10 / 0` i odczytaj typ błędu.
- **EN:** Attempt `10 / 0` inside try/except and print error type and message.
- **Rozwiązanie:** [`solutions/task_10.py`](solutions/task_10.py)
### Zadanie 11: List Length Inspection
- **Treść:** Utwórz listę `[5, 10, 15]` i sprawdź `len(lista)`.
- **EN:** Create list `[5, 10, 15]` and check `len(my_list)`.
- **Rozwiązanie:** [`solutions/task_11.py`](solutions/task_11.py)
### Zadanie 12: Substring Search
- **Treść:** Sprawdź, czy napis 'programowanie' zawiera podnapis 'gram'.
- **EN:** Check whether 'gram' is present in 'programming' using the `in` keyword.
- **Rozwiązanie:** [`solutions/task_12.py`](solutions/task_12.py)
### Zadanie 13: String Multiplication
- **Treść:** Oblicz `'Ha' * 5`.
- **EN:** Calculate `'Ha' * 5` and inspect the repeated string.
- **Rozwiązanie:** [`solutions/task_13.py`](solutions/task_13.py)
### Zadanie 14: Type of None
- **Treść:** Sprawdź, co zwróci `type(None)`.
- **EN:** Inspect `type(None)`.
- **Rozwiązanie:** [`solutions/task_14.py`](solutions/task_14.py)
### Zadanie 15: Built-in Docstring Help
- **Treść:** Wpisz `help(print)` i przeczytaj dokumentację.
- **EN:** Inspect docstring of `print` function using `print.__doc__`.
- **Rozwiązanie:** [`solutions/task_15.py`](solutions/task_15.py)
