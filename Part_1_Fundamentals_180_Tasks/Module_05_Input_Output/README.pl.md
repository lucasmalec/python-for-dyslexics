# Moduł 5: Wejście i Wyjście

[🇬🇧 English](README.md) | [🇵🇱 Polski](README.pl.md)

---

## 🎯 O tym module
Nauka interakcji z użytkownikiem przez input() oraz precyzyjnego formatowania wyników za pomocą print().

- **Limit wizualny:** Maksymalnie 88 znaków w wierszu (standard PEP 8 / Black).
- **Format:** 15 praktycznych zadań krok po kroku z gotowymi rozwiązaniami w języku angielskim.

---

## 📝 15 Praktycznych Zadań

### Zadanie 01: User Greeting
- **Treść:** Zapytaj użytkownika o imię i przywitaj się komunikatem: 'Cześć, [imię]!'.
- **EN:** Ask user for name and display greeting: 'Hello, [name]!'.
- **Rozwiązanie:** [`solutions/task_01.py`](solutions/task_01.py)
### Zadanie 02: Age Confirmation
- **Treść:** Zapytaj o wiek i wyświetl: 'Masz [wiek] lat.'.
- **EN:** Ask user for age and display: 'You are [age] years old.'.
- **Rozwiązanie:** [`solutions/task_02.py`](solutions/task_02.py)
### Zadanie 03: Two Numbers Sum
- **Treść:** Poproś o dwie liczby, a następnie wyświetl ich sumę.
- **EN:** Prompt user for two numbers, parse them, and print their sum.
- **Rozwiązanie:** [`solutions/task_03.py`](solutions/task_03.py)
### Zadanie 04: Number Squared
- **Treść:** Poproś o liczbę i wyświetl jej kwadrat.
- **EN:** Ask for a number and print its square.
- **Rozwiązanie:** [`solutions/task_04.py`](solutions/task_04.py)
### Zadanie 05: Favorite Color
- **Treść:** Zapytaj o ulubiony kolor i wyświetl: 'Twój ulubiony kolor to [kolor].'.
- **EN:** Ask user for favorite color and display formatted confirmation.
- **Rozwiązanie:** [`solutions/task_05.py`](solutions/task_05.py)
### Zadanie 06: Three Numbers Mean
- **Treść:** Poproś o trzy liczby i oblicz ich średnią.
- **EN:** Prompt user for three numbers and calculate their arithmetic mean.
- **Rozwiązanie:** [`solutions/task_06.py`](solutions/task_06.py)
### Zadanie 07: Location Formatter
- **Treść:** Zapytaj o miasto i kraj, a następnie wyświetl: 'Mieszkasz w [miasto], [kraj].'.
- **EN:** Ask user for city and country, then print: 'You live in [city], [country].'.
- **Rozwiązanie:** [`solutions/task_07.py`](solutions/task_07.py)
### Zadanie 08: Float Precision Formatter
- **Treść:** Poproś o liczbę rzeczywistą i wyświetl ją z dokładnością do 2 miejsc po przecinku.
- **EN:** Prompt for a real number and display it formatted to 2 decimal places.
- **Rozwiązanie:** [`solutions/task_08.py`](solutions/task_08.py)
### Zadanie 09: Integer Division and Remainder
- **Treść:** Poproś o dwie liczby całkowite, a następnie wyświetl wynik dzielenia całkowitego i resztę.
- **EN:** Prompt for two integers, then display both floor quotient and modulo remainder.
- **Rozwiązanie:** [`solutions/task_09.py`](solutions/task_09.py)
### Zadanie 10: Uppercase Transformation
- **Treść:** Zapytaj o tekst i wyświetl go wielkimi literami.
- **EN:** Ask user for text input and print it completely in UPPERCASE.
- **Rozwiązanie:** [`solutions/task_10.py`](solutions/task_10.py)
### Zadanie 11: Birth Year to Age Calculator
- **Treść:** Zapytaj o rok urodzenia i oblicz wiek (przyjmij bieżący rok = 2026).
- **EN:** Prompt for birth year and calculate current age (reference year = 2026).
- **Rozwiązanie:** [`solutions/task_11.py`](solutions/task_11.py)
### Zadanie 12: Rectangle Geometry
- **Treść:** Poproś o długość i szerokość prostokąta, wyświetl pole i obwód.
- **EN:** Prompt for rectangle length and width, then compute and print area and perimeter.
- **Rozwiązanie:** [`solutions/task_12.py`](solutions/task_12.py)
### Zadanie 13: Name and Lucky Number
- **Treść:** Zapytaj o imię i liczbę, a następnie wyświetl: 'Cześć [imię]! Twoja liczba to [liczba].'.
- **EN:** Prompt for name and favorite number, display: 'Hello [name]! Your number is [number].'.
- **Rozwiązanie:** [`solutions/task_13.py`](solutions/task_13.py)
### Zadanie 14: Sum Check on Three Inputs
- **Treść:** Poproś o trzy liczby i sprawdź, czy pierwsza jest sumą dwóch kolejnych.
- **EN:** Prompt for three numbers and verify if the first equals the sum of the other two.
- **Rozwiązanie:** [`solutions/task_14.py`](solutions/task_14.py)
### Zadanie 15: Product Invoice Summary
- **Treść:** Zapytaj o nazwę produktu i cenę netto, wyświetl cenę brutto (23% VAT).
- **EN:** Prompt for product name and net price; compute gross price using 23% VAT.
- **Rozwiązanie:** [`solutions/task_15.py`](solutions/task_15.py)
