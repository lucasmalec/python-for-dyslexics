# Module 5: Input and Output

[🇬🇧 English](README.md) | [🇵🇱 Polski](README.pl.md)

---

## 🎯 About This Module
Master interactive terminal prompts via input() and formatted console streams with print().

- **Visual Limit:** Max 88 characters per line (PEP 8 / Black standard).
- **Format:** 15 hands-on progressive tasks with full English solutions.

---

## 📝 15 Hands-on Tasks

### Task 01: User Greeting
- **Requirement:** Ask user for name and display greeting: 'Hello, [name]!'.
- **PL:** Zapytaj użytkownika o imię i przywitaj się komunikatem: 'Cześć, [imię]!'.
- **Solution:** [`solutions/task_01.py`](solutions/task_01.py)
### Task 02: Age Confirmation
- **Requirement:** Ask user for age and display: 'You are [age] years old.'.
- **PL:** Zapytaj o wiek i wyświetl: 'Masz [wiek] lat.'.

### Task 03: Two Numbers Sum
