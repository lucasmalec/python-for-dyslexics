## 🎯 About This Module
Explore arithmetic, comparison, logical, augmented assignment, and operator precedence.

- **Visual Limit:** Max 88 characters per line (PEP 8 / Black standard).
- **Format:** 15 hands-on progressive tasks with full English solutions.

- **Solution:** [`solutions/task_01.py`](solutions/task_01.py)

- **PL:** Oblicz resztę z dzielenia 29 przez 6.
- **Solution:** [`solutions/task_02.py`](solutions/task_02.py)
### Task 03: Exponentiation
- **Requirement:** Calculate 2 to the power of 8 using the `**` operator.
- **PL:** Oblicz 2 do potęgi 8.
- **Solution:** [`solutions/task_03.py`](solutions/task_03.py)
### Task 04: Floor Division

### Task 05: Augmented Assignment Operators
