# Moduł 2: Podstawowe Typy Danych

[🇬🇧 English](README.md) | [🇵🇱 Polski](README.pl.md)

---

## 🎯 O tym module
Zrozumienie podstawowych typów wbudowanych: int, float, str, bool oraz stałej NoneType.

- **Limit wizualny:** Maksymalnie 88 znaków w wierszu (standard PEP 8 / Black).
- **Format:** 15 praktycznych zadań krok po kroku z gotowymi rozwiązaniami w języku angielskim.

---

## 📝 15 Praktycznych Zadań

### Zadanie 01: Four Primitive Types
- **Treść:** Utwórz zmienne: `liczba_calkowita = 10`, `ulamek = 3.14`, `tekst = 'Python'`, `czy_prawda = True`. Wyświetl typ każdej z nich.
- **EN:** Create variables: `int_val = 10`, `float_val = 3.14`, `text_val = 'Python'`, `bool_val = True`. Display type of each.
- **Rozwiązanie:** [`solutions/task_01.py`](solutions/task_01.py)
### Zadanie 02: Float Inspection
- **Treść:** Sprawdź typ wartości `3.1415` za pomocą funkcji `type()`.
- **EN:** Check type of value 3.1415 using `type()`.
- **Rozwiązanie:** [`solutions/task_02.py`](solutions/task_02.py)
### Zadanie 03: Boolean Flag
- **Treść:** Utwórz zmienną `czy_slonecznie = False` i wyświetl jej typ.
- **EN:** Create variable `is_sunny = False` and print its type.
- **Rozwiązanie:** [`solutions/task_03.py`](solutions/task_03.py)
### Zadanie 04: String Concatenation Fix

- **EN:** Combine string 'I am ' with number 30 and ' years old' using string conversion.
- **Rozwiązanie:** [`solutions/task_04.py`](solutions/task_04.py)
### Zadanie 05: String to Integer Conversion

### Zadanie 06: Type of Booleans
