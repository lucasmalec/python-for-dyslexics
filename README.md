## 🧭 Manifesto: Why This Course Exists

Traditional programming courses are written for linear, verbal thinkers. They drown learners in dry syntax, arbitrary rules, and dozens of disconnected commands without real-world context.

For **dyslexic, visual, and spatial thinkers**, abstract words and syntax tables are exhausting. Our brains think in **spatial models, visual systems, and structured patterns** (*Input → Process → Output*). When forced into rote memorization, brilliant spatial thinkers get frustrated and abandon programming.

**Python for Dyslexics flips the approach:**
1. **Whole-Picture Architecture First:** You see what the complete machine does before looking at individual nuts and bolts.
2. **Predictable Modular Rhythm:** Exactly 15 progressive tasks per fundamental module. No infinite scrolling, no sudden difficulty spikes.
3. **88-Character Visual Boundary:** Strict line-length limit prevents horizontal scanning fatigue and line skipping.
4. **Defensive Engineering Mindset:** Learn how to sanitize inputs, catch exceptions, and handle edge cases right from day one.
5. **Real-World Systems Focus:** Progress smoothly from basic variables to real-world sysadmin scripts, backup managers, REST APIs, and OOP architecture.
